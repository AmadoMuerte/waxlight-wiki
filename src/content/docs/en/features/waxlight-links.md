[waxlight.by](https://waxlight.by) turns Vintage Story mods and servers into regular HTTPS links that can be shared on Discord, forums, and websites. Opening one passes it to Waxlight and shows the relevant page directly in the launcher.

## Mod links

Link format:

```text
https://waxlight.by/mod/{mod-slug}
```

Waxlight opens the mod's ModDB page. You can then choose an instance and explicitly confirm installation through the regular [mod catalog](/en/features/mods/) flow.

## Server links

Link format:

```text
https://waxlight.by/server/{server-address}
```

Waxlight opens the Servers section and shows that server's details. To connect, click **Play** and select an instance.

The browser may ask for permission to open Waxlight the first time. If the launcher is not installed, the page keeps download links available.

:::note[Navigation only]
A link never installs a mod or joins a server automatically. The user confirms every action in Waxlight.
:::

The service requires no account and uses no database, cookies, analytics, or telemetry.
