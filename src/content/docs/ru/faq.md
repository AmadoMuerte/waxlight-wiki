## Общее

### Waxlight — официальный лаунчер Vintage Story?

Нет. Waxlight — независимый открытый проект, не аффилированный с Anego Studios и разработчиками Vintage Story. Лаунчер не распространяет игру и не обходит её лицензирование: нужен действующий аккаунт Vintage Story.

### На каких платформах работает Waxlight?

Windows x64 и Linux x64. Пакеты: установщик и portable ZIP для Windows; `.deb`, `.rpm` и portable `.tar.gz` для Linux. NixOS поддерживается через официальный Nix flake на `x86_64-linux`; см. страницу [NixOS](/ru/features/nixos/).

### Где скачивать Waxlight?

Только на странице [GitHub Releases](https://github.com/AmadoMuerte/Waxlight-launcher/releases/latest) официального репозитория. Каждый релиз содержит `SHA256SUMS` для проверки целостности.

## Установка и обновления

### Windows показывает предупреждение SmartScreen. Это безопасно?

Неподписанные сборки Waxlight могут вызывать SmartScreen. Скачивайте только с официальной страницы Releases и проверяйте SHA-256. Подробнее — [«Подпись кода»](/ru/policies/code-signing/).

### Почему автообновление на Windows не устанавливается автоматически?

Так задумано. Поскольку доверенный издатель не настроен, лаунчер после проверки контрольной суммы отклоняет автоматическую установку неподписанных обновлений. Скачайте новую версию вручную со страницы Releases. См. [«Обновления лаунчера»](/ru/features/updates/).

### Почему Vintage Story не запускается в Windows с ошибкой DLL `nanosvg`?

Установите **Microsoft Visual C++ Redistributable 2015–2022 (x64)** со страницы Microsoft [последних поддерживаемых загрузок](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170), затем снова запустите игру.

### Куда Waxlight складывает данные?

Linux: `~/.config/waxlight/`; Windows: `%AppData%\waxlight\`. Папку можно перенести в **Настройки → Папка данных**. Каталог назначения должен быть доступен для записи; для внешнего диска Windows держите его подключённым и выбирайте место, где Waxlight может создавать и перемещать файлы. При ошибке переноса исходные данные остаются на месте.

## Аккаунты и безопасность

### Где хранятся мои пароль и сессия?

Пароли и TOTP-коды не сохраняются вообще. Сессионные ключи — только в системном хранилище: Secret Service (GNOME Keyring/KWallet) на Linux и Credential Manager на Windows. Подробнее — [«Аккаунты и вход»](/ru/features/accounts/).

### Удаление аккаунта из лаунчера завершает сессию на сервере?

Нет. Удаление локальное: стираются ключи, метаданные и связи инстансов. Используемого эндпоинта отзыва сессий у Vintage Story нет.

### Что отправляет телеметрия?

По умолчанию — ничего: телеметрия выключена. Если включить, отправляются только псевдонимный ID установки, версия лаунчера, ОС/архитектура, количества инстансов и модов и предопределённые имена событий/коды ошибок. Полный список — в [политике конфиденциальности](/ru/policies/privacy/).

## Игра и моды

### Можно ли держать несколько версий игры?

Да, версии устанавливаются рядом в общее хранилище `versions/`, и каждому инстансу назначается своя версия. См. [«Версии игры»](/ru/features/game-versions/).

### Как поделиться сборкой модов с другом?

Экспортируйте инстанс как пакет Waxlight: учётные данные и машинно-специфичные настройки вырезаются автоматически. Друг импортирует пакет и выберет свой аккаунт. См. [«Пакеты инстансов»](/ru/features/packages/).

### Инстанс сломался после обновления модов. Что делать?

Используйте механизмы восстановления: страховочные копии и «последнее известное хорошее состояние». См. [«Бэкапы и восстановление»](/ru/features/backups/).
